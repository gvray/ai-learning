# Large Language Models

This page is written in `.mdx` — in addition to plain Markdown, it can embed interactive components.

## Key Technologies

- **Transformer architecture**: self-attention mechanism
- **Pretraining**: learns language representations from massive unlabeled text
- **Fine-tuning (SFT / RLHF)**: aligns with human preferences

## Example: API Call

```python
from anthropic import Anthropic

client = Anthropic()
message = client.messages.create(
    model="claude-sonnet-4",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain the attention mechanism"}],
)
```
