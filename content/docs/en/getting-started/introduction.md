# Learning Path

This page is written in plain Markdown (`.md`), demonstrating that ordinary Markdown documents work directly as pages.

## Prerequisites

- **Math fundamentals**: linear algebra, probability, calculus
- **Programming basics**: Python syntax and common libraries (NumPy / Pandas)
- **English reading**: ability to read papers and technical docs

## Recommended Order

1. Machine learning fundamentals
2. Neural networks and backpropagation
3. Deep learning frameworks (PyTorch)
4. Large language models and Transformers

> Tip: Follow the sidebar order, and use search to look up unfamiliar concepts anytime.
