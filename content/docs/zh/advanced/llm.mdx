# 大语言模型

本页用 `.mdx` 写成——除了普通 Markdown，还能嵌入交互组件。

## 关键技术

- **Transformer 架构**：自注意力机制
- **预训练**：海量无监督文本学习语言表示
- **微调（SFT / RLHF）**：对齐人类偏好

## 示例：调用 API

```python
from anthropic import Anthropic

client = Anthropic()
message = client.messages.create(
    model="claude-sonnet-4",
    max_tokens=1024,
    messages=[{"role": "user", "content": "解释注意力机制"}],
)
```
